How to convert a text list to an array

A text list to array converter takes a plain list of values — one per line, the way it comes out of a spreadsheet column, a log file or a database export — and rewrites it as an array literal you can paste straight into code. ArrayHelper does it for every target language at once, in three steps.

  1. Paste your list One value per line. Blank lines are skipped and leading or trailing spaces are trimmed automatically, so copy-pasted columns work exactly as they are.
  2. Pick your rules Single or double quotes, plain or quoted numbers, duplicate removal, SQL dialect, and up to three output panels side by side. Your choices are remembered on this device.
  3. Copy the array Press Ctrl / Cmd + Enter — or leave Auto Run on — then copy the JavaScript, SQL, Python, PHP, JSON, C# or custom output with one click.

One text list, every array format

The same list is converted into all of the formats below at the same time. Numbers stay numbers, text is quoted, and quotes inside your values are escaped for the target language.

Input list

apple
banana
42

What you get

Eight ready-to-paste outputs, generated as you type. Keep the three formats you use most open side by side, or switch panels whenever the target language changes.

JavaScript / TypeScript array

['apple', 'banana', 42]

A plain array literal for JS, TS and Node. Switch to double quotes when your linter asks for them.

SQL IN clause

IN (N'apple', N'banana', N'42')

Ready for WHERE column IN (...). N'...' for SQL Server, or switch the dialect to get '...' for MySQL, PostgreSQL and SQLite.

Python list

['apple', 'banana', 42]

Drop it into a script, a fixture or a pytest parametrize block without retyping a single comma.

PHP array

array('apple', 'banana', 42)

Classic array() syntax that also works inside older codebases and Laravel config files.

JSON array

["apple", "banana", 42]

Strictly valid JSON with proper string escaping — safe to paste into an API request body or a fixture file.

C# array

new[] { "apple", "banana", 42 }

An implicitly typed array for C# and .NET, built from the same JSON-escaped values.

Raw comma separated list

'apple', 'banana', 42

No brackets at all — the quoted, comma separated body you can drop into any language that is not on this list.

Custom pattern

EXEC MyProcedure 'apple';
EXEC MyProcedure 'banana';
EXEC MyProcedure '42';

Write your own template with {} for the value, {n} for the row number and {i} for the zero-based index.

Text list to array: frequently asked questions

What is a text list to array converter?

It is a tool that takes a plain list of values — one per line — and rewrites it as an array literal you can paste straight into code. ArrayHelper produces JavaScript, SQL, Python, PHP, JSON, C# and custom output from the same list at the same time, so you never hand-type quotes and commas again.

How do I convert a text list to an array online?

Paste the list into the editor at the top of this page, press Ctrl / Cmd + Enter or leave Auto Run on, then copy the panel you need. There is nothing to install, no sign-up and no row limit.

Does it escape quotes and special characters?

Yes. Single quotes are doubled for SQL, and the JSON and C# outputs use real JSON string escaping, so values containing quotes, backslashes or tabs stay valid in the target language.

Are numbers quoted?

By default plain numeric lines are emitted as numbers and everything else is quoted. Use the numbers toggle in the toolbar if you want numeric values quoted as strings too.

Can I remove duplicate lines while converting?

Turn on Dedupe in the options menu. Duplicate lines are dropped and the first occurrence is kept. Blank lines and surrounding whitespace are always trimmed, with or without Dedupe.

How large a list can it handle?

The classic editor works with lists up to 50,000 lines, and the Ultra editor keeps even larger pastes responsive. Very long outputs are truncated on screen for speed, but Copy always returns the complete array.

Is my list uploaded to a server?

No. Every conversion runs locally in your browser with JavaScript and your list never leaves your device, which makes the tool safe for internal identifiers and customer data.

Can I define my own output format?

Yes. The Custom panel takes a template such as EXEC MyProcedure '{}';, where {} is the line value, {n} the row number starting at 1 and {i} the zero-based index. Each line is rendered with the template on its own row.

Which SQL dialect does the IN clause use?

Both are supported. N'...' is used for SQL Server by default; switch the SQL setting to '...' for MySQL, PostgreSQL, SQLite and other standard dialects.
